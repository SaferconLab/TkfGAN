# TkfGan

This study proposes an innovative time series anomaly detection framework named TkfGAN, whose core technology lies in the systematic integration of the Kalman filter  with the TadGAN model. By incorporating the dynamic system modeling capability of Kalman filtering, we effectively address stability issues in temporal feature extraction inherent to conventional generative adversarial networks, thereby establishing a dual-channel detection architecture with adaptive noise suppression capabilities.

For experimental validation, this research employs publicly available benchmark datasets including NASA and NAB for multi-dimensional comparative analysis. Additionally, the framework is trained and validated using real-world operational data from a nuclear power plant to demonstrate its practical effectiveness. Evaluation metrics such as F1-score and recall rate are utilized to assess experimental outcomes. This project provides a novel technical approach for real-time monitoring in industrial anomaly detection domains.
